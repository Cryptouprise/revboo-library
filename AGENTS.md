# RevBoo shared agent entry point

Applies to ChatGPT/Codex, Claude, Grok and human editors working in this repository.
Read `docs/AGENT_WORKFLOW.md` before any asset intake or revision. It is the common production and filing contract. Read README.md for existing media storage commands. Use `catalog/registry.json` for permanent conversational IDs and approval state; use `manifest.json` for existing media URLs and gallery metadata. Do not maintain a second authoritative registry.

Never treat README's historic `final` status or newest timestamp as launch approval. Preserve original media, previous release assets, IDs and approval evidence. Never upload unpublished client material to this public repository without authorization to publish it. No credentials or private file identifiers in public metadata.

When permissions or tools are missing, prepare the handoff described in the workflow and say it has not been uploaded. Do not claim a proposed upload, unexecuted sync or incomplete review succeeded.
